# Lumae releases

Signed and notarized builds of Lumae, and the Sparkle update feed (`appcast.xml`), are attached to the releases of this repository.

To install, download the latest `Lumae-<version>.dmg` from the Releases page, open it, and drag Lumae into the Applications folder. Installed copies update themselves; the `.zip` and `.delta` files are what the updater downloads.
